# 거실 컨셉 수정 기록

기본 내장 이미지 편집 도구(image_gen) 사용. 기존 각 컨셉을 편집 대상으로 사용하고 사용자 첨부 TV벽·실링팬·직사각형 에어컨 사진은 디테일 참고로 사용했다. 참고 사진 자체를 사이트에 복사하지 않았다.

## 편집 지시 / 프롬프트 요약

- 01 long-datum-v7: 원래 구조·TV·창·바닥·벤치 유지. 수직 우드 진열 선반을 베란다와 TV벽 코너로 옮기고 양옆 간접조명. 정사각 AC를 창가 쪽 슬림 직사각형으로 변경, 참고의 화이트 3엽 실링팬 추가.
- 02 gallery-ldk-v7: 기존 거실에서 TV벽을 참고 사진의 화이트 돌출 면·하부 석재 라인·우측 유리 니치로 편집. 주방 천정 AC 제거. 카메라를 우측으로 좁혀 TV벽 강조. 소파·테이블 제거, 화이트 실링팬 추가.
- 04 platform-v7: TV협탁·펜던트·소파·테이블·러그 제거. 창가 평상을 동일 높이의 ㄱ자로 좌측 벽까지 연결, 방석 추가. 우드 실링팬, 창가 쪽 슬림 AC. 원래 구조·TV·창·커튼 유지.
- 05 soft-classic-v7: 우측 파란 의자 2개·러그·테이블 제거. 기존 크림 소파를 창가 쪽으로 약간 옮기고 살짝 회전. 기존 조명 켜기. 몰딩·벽난로·아치·바닥·카메라 유지.
- 08 korean-calm-v7: 카메라를 우측 거실 중심으로 변경. 짙은 우드 마루, 한지 질감 벽과 절제된 목재 천정 테두리 및 살창으로 한국적 현대 공간 표현. 창가 쪽 슬림 AC, 커튼 앞 식물 연출. 아파트 구조와 현실적인 크기 유지.
- 11 library-lounge-v2: 기존 독립 소파·테이블·러그·싱글 의자 제거. 우측 책장 중앙을 쿠션 소파 니치로 통합. 창가 쪽 슬림 직사각 AC. 기존 조명과 책장 조명 켜기. 원래 구조·좌측 TV·창·바닥 유지.

공통 프롬프트 제약: photorealistic architectural interior, preserve unspecified architecture, realistic scale, straight perspective, single full-bleed image, no text or border. 이미지 원본 픽셀 크기를 변경하지 않고 저장했다. 표시에는 object-fit:cover를 사용하여 카드의 여백을 제거한다.

삭제: 사용자 지정 03·07·09·13·14·15·16·17·18·19·20의 현재 표시 파일 11개. Git 추적 파일이므로 기존 커밋에서 복구 가능. 다른 번호의 과거 시안 파일은 이번 삭제 범위에 포함하지 않는다.
남은 번호: 01·02·04·05·06·08·10·11·12. 06·10·12 이미지는 변경하지 않는다.
