# 공간한쪽 레퍼런스 채널 전수 분석 운영표준

## 목적

공개 영상의 디자인이나 표현을 모방하는 것이 아니라, 실제 고객 제안에 필요한 현장 판단·시공·견적·안전·하자·관리 원리를 추출해 출처와 함께 공간한쪽 지식베이스로 축적한다.

## 1차 분석 채널

### 국내

- 인테리언니 백예진: 공간 기획, 디자인 완성도, 자재 선택, 현장 경험과 소비자 관점
- 오늘의집: 생활 문제, 작은 공간, 동선·수납, 전후 변화
- 쿤하우스: 셀프 시공 과정, 공구, 재료비, 구축 보수와 실패 경험
- 아정당 인테리어: 견적, 계약, 업체 검증, 추가금과 A/S

### 해외

- This Old House: 전문가 진단, 주택 시스템, 공종별 표준
- Home RenoVision DIY: 전체 리모델링 공정과 DIY 난이도
- See Jane Drill: 초보자 공구 사용과 기초 집수리
- Vancouver Carpenter: 석고보드, 퍼티와 바탕면 품질
- Home Repair Tutor: 욕실, 타일과 방수
- Got2Learn: 급수·배수, 누수와 배관 원리
- Everyday Home Repairs: 유지관리와 소규모 수선
- Family Handyman: 작업별 실용 팁과 공구

## 영상별 기록 항목

1. 채널, 영상 ID, 제목, 주소, 게시일, 영상 길이
2. 공간: 주방·욕실·거실·침실·수납·현관·베란다·전체
3. 공종: 철거·목공·전기·설비·방수·타일·도장·필름·도배·바닥·가구·조명
4. 콘텐츠 유형: 설계 사례·시공법·공구·제품·견적·계약·하자·유지관리
5. 현장 조건과 작업 전 확인사항
6. 준비물, 공구, 보호구, 인원과 예상 시간
7. 공정 순서와 건조·양생 조건
8. 장점, 단점, 적용 조건과 추천하지 않는 조건
9. 흔한 실패, 중단 기준, 전문가 전환 기준
10. 자재·수량·단가·구매처와 가격 확인 시점
11. 완료 검수, 사후 관리와 A/S
12. 국내 적용 시 규격·법규·주거 방식 차이
13. 공간한쪽 프로토콜에 반영할 원칙
14. 사실·제작자 의견·광고성 주장 구분

## 전수 분석 절차

`전체 영상 목록 확보 → 중복·비관련 표시 → 제목·설명 1차 분류 → 자막·화면 내용 분석 → 원칙 추출 → 교차 검증 → 프로토콜 반영 → 출처 연결`

각 영상은 다음 상태 중 하나를 갖는다.

- `목록화`: 영상 기본 정보 확보
- `분류 완료`: 공간·공종·콘텐츠 유형 태깅
- `내용 분석`: 자막과 화면의 핵심 내용 검토
- `검증 필요`: 국내 규격·법규·제품 정보 확인 필요
- `반영 완료`: 사이트 또는 제안서 규칙에 반영
- `제외`: 광고·중복·비관련 등 사유 기록

## 품질과 저작권 원칙

- 영상 대본, 이미지, 도면과 고유한 디자인을 그대로 저장하거나 복제하지 않는다.
- 짧은 사실 확인을 제외한 원문 인용 대신 요약된 판단 원칙을 기록한다.
- 서로 다른 채널의 의견이 충돌하면 하나를 정답으로 만들지 않고 현장 적용 조건을 비교한다.
- 전기·가스·구조·방수·매립 배관은 해외 영상만으로 국내 시공 가능 여부를 판단하지 않는다.
- 가격, 제품 재고, 법규, 면허와 보증 조건은 고객 제안서를 만들 때 다시 확인한다.
- 협찬·판매·시공업체가 제작한 콘텐츠는 상업적 이해관계를 표시하고 독립 자료로 교차 확인한다.

## 공간한쪽 결과물 연결

- 생활 문제와 전후 변화 → 현장 분석서·설계 시안
- 자재 비교와 관리 정보 → 마감재 선택표
- 작업법과 실패 사례 → 셀프 작업 카드
- 공정과 양생 조건 → 공정표·발주표
- 비용과 수량 정보 → 상세 견적서
- 하자와 수리 사례 → 검수·A/S 체크리스트
- 업체·계약 정보 → 업체 비교표·변경 승인서

## 업데이트 원칙

- 분석일과 원본 영상 주소를 보존한다.
- 삭제·비공개 영상은 상태만 변경하고 기존 분석의 출처 상태를 표시한다.
- 신규 영상은 정기적으로 목록에 추가하되 기존 표준을 자동 변경하지 않는다.
- 같은 주제의 근거가 누적되면 공간 유형, 바탕 상태, 숙련도에 따라 조건부 기준으로 정리한다.
