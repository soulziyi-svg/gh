# 공간한쪽 표준 프로토콜

## 1. 서비스 목적

공간한쪽은 예쁜 이미지만 제안하지 않는다. 사진과 실측을 설계, 마감재, 물량, 견적, 발주, 시공, 검수까지 연결해 셀프 인테리어 고객의 선택 실패와 예산 낭비를 줄인다.

핵심 흐름은 다음과 같다.

`사진·실측 입력 → 현장 조건 분석 → 설계 시안 → 선택 장단점 비교 → 셀프/전문가 구분 → 상세 견적 → 발주·공정·검수 → 사후 데이터 반영`

## 2. 공통 판단 원칙

1. 사진으로 보이지 않는 구조, 전기, 가스, 배관, 방수, 바탕면은 추측해 확정하지 않는다.
2. 디자인보다 안전, 사용성, 관리성, 보수 가능성을 먼저 확인한다.
3. 인기와 유행만으로 추천하지 않는다.
4. 추천에는 적용 조건, 장점, 단점, 추천하지 않는 경우를 함께 기록한다.
5. 가격과 재고에는 판매처, 확인 날짜, 배송비·부가세 포함 여부를 기록한다.
6. 예상 수량에는 산출식, 손실률, 포장 단위, 최종 발주 수량을 표시한다.
7. 견적에는 포함·제외 항목과 추가 비용 발생 조건을 명시한다.
8. 출처가 있는 사례는 복제하지 않고 원리를 분석해 공간한쪽의 표현으로 재구성한다.

## 3. 고객 입력 정보

### 기본 정보

- 건물 유형, 지역, 준공 연도, 층수, 엘리베이터 유무
- 공실 공사 또는 거주 중 공사
- 공사 공간과 희망 일정
- 전체 예산과 절대 넘기기 어려운 상한
- 유지할 가구·가전의 모델과 실제 규격

### 사진·실측

- 공간 전체가 보이는 네 방향 사진
- 천장, 바닥, 창호, 문, 콘센트, 배관, 설비 사진
- 가로·세로·높이, 창과 문의 위치·크기
- 기둥, 보, 단차, 배관 박스 등 돌출부 치수
- 분전반, 수도 밸브, 배수구 등 설비 위치

### 생활 방식

- 가족 구성, 아이·노약자·반려동물 여부
- 요리, 청소, 수납, 재택근무 습관
- 선호 스타일, 색상, 밝기, 관리 가능 시간
- 현재 가장 불편한 점과 반드시 유지할 요소

## 4. 현장 분석서

각 항목은 `확인됨 / 사진상 추정 / 추가 실측 필요 / 전문가 확인 필요 / 철거 후 확인`으로 표시한다.

- 구조와 동선
- 바닥·벽·천장 바탕 상태
- 창호·단열·결로 가능성
- 전기 용량, 콘센트, 조명 회로
- 급수·배수·가스·환기
- 욕실 방수와 배수 경사
- 철거 범위, 폐기물, 반출 동선
- 관리사무소 신고, 작업 시간, 엘리베이터 보양 조건
- 안전 위험과 공사 전 선행 작업

## 5. 설계·마감재 제안서

### 설계안

- 요구사항과 문제 정의
- 평면·동선 제안
- 3D 또는 이미지 시안
- 조명, 수납, 가구·가전 배치
- 합리형·균형형·프리미엄형 대안
- 예산이 줄어도 유지할 핵심 요소와 대체 가능한 요소

### 마감재 표준 항목

- 분류, 적용 공간, 브랜드, 제품명, 모델명, 규격, 색상
- 표면 마감, 성능, 인증 또는 등급
- 실측 필요량, 손실률, 포장 단위, 발주 수량
- 단가, 배송비, 최소 주문 수량, 예상 합계
- 판매처, 구매 링크, 가격 확인 날짜
- 재고·로트·반품·A/S 조건
- 장점, 단점, 청소·보수·교체 난이도
- 추천 이유, 추천하지 않는 조건, 대체 제품
- 실물 샘플 확인 여부

### 마감재 평가 항목

- 디자인 적합성
- 가격 경쟁력
- 시공 난이도
- 오염·습기·스크래치·미끄럼 내구성
- 청소와 유지관리
- 부분 보수와 교체 가능성
- 국내 재고와 A/S
- 셀프 시공 가능성
- 장기 사용 가치

평가 결과는 단일 총점뿐 아니라 항목별 근거를 함께 제시한다.

## 6. 작업 방식과 안전 등급

- `A 초보자 가능`: 기본 손공구와 설명으로 가능한 작업
- `B 경험 필요`: 전동공구 사용과 정밀 작업 경험 필요
- `C 부분 외주 권장`: 보조 인원, 특수 공구 또는 일부 전문가 작업 필요
- `D 전문가 시공 권장`: 하자 위험과 재시공 비용이 큰 작업
- `E 전문가 확인 필수`: 전기, 가스, 구조, 방수 등 안전·법규·책임 확인이 필요한 작업

표시 태그는 `셀프 가능 / 부분 외주 권장 / 전문가 시공 권장 / 조건부 추천 / 현장 조건 확인 / 유행보다 관리 / 추가 실측 필요 / 비용 대비 효과 낮음`을 사용한다.

## 7. 상세 견적 원칙

### 견적 신뢰도

- `L1 초기 예상`: 사진과 대략 치수 기반, 범위형 금액
- `L2 실측 가견적`: 상세 실측과 사양 반영
- `L3 현장 확인`: 작업자 현장 확인 반영
- `L4 업체 확정`: 범위·단가·일정 합의
- `L5 발주 확정`: 실제 주문 가격과 배송비 반영

### 기본 견적 열

- 공간, 공종, 세부 작업, 작업 방식, 필수·선택 구분
- 산출 근거, 가로, 세로, 높이, 개수, 산출식
- 실측 수량, 손실률, 계산 수량, 포장 단위, 발주 수량
- 단위, 자재 단가, 노무 단가, 장비·경비 단가
- 자재비, 노무비, 장비비, 운반비, 폐기물비, 기타 경비
- 공급가액, 부가세, 총액
- 포함 사항, 제외 사항, 추가 비용 조건
- 견적 신뢰도, 출처, 확인 날짜, 비고

### 반드시 검토할 숨은 비용

- 보양, 양중, 주차, 엘리베이터 사용·보증금
- 철거, 분류, 마대, 반출, 폐기물 처리
- 배송, 재배송, 반품, 현장 보관
- 바탕면·수평·균열·누수 보수
- 공구 구매·대여와 소모품
- 관리사무소 신고, 입주청소, 공정 지연
- 디자인 변경과 재시공
- 공사 성격에 따른 예비비 5~15%

### 수량 산출 원칙

- 면적·길이·개수 산출 근거를 셀 수식으로 남긴다.
- 손실률은 자재, 패턴, 시공 방향, 공간 형태에 따라 별도 적용한다.
- 실측 수량과 판매 포장 단위를 분리한다.
- 타일·마루·벽지는 로트 차이를 고려해 한 번에 발주한다.
- 철거 물량은 면적뿐 아니라 무게, 부피, 해체 난이도, 반출 조건을 반영한다.

## 8. 공정·발주·변경 관리

기본 공정은 현장에 맞춰 다음 순서를 조정한다.

`신고·보양 → 철거 → 설비·전기 → 목공 → 방수·타일 → 도장·필름 → 바닥·도배 → 가구 → 조명·기구 → 청소 → 검수`

각 공정에 작업일, 선행 조건, 건조 시간, 담당자, 자재 도착일, 다음 공정 영향을 기록한다.

발주표에는 필요량, 발주량, 판매처, 주문일, 도착 예정일, 로트, 보관 조건, 반품 기한, 여분 수량, 대체 제품을 기록한다.

변경표에는 최초 계약 금액, 변경 내용과 이유, 추가·감액 금액, 승인자, 승인일, 최종 예상 금액과 관련 사진을 기록한다.

## 9. 검수와 사후 관리

중간검수와 준공검수를 분리한다.

- 타일 들뜸, 구배, 줄눈, 모서리
- 욕실 방수, 배수, 실리콘, 누수
- 문·서랍 간섭, 가구 수평·수직
- 콘센트, 스위치, 조명 회로와 색온도
- 도배 이음, 들뜸, 오염
- 마루 단차, 찍힘, 걸레받이
- 급수·배수 작동과 누수
- 보수 완료 사진, A/S 담당과 기간

완공 후 예상 대비 실제 물량, 비용, 기간, 추가 비용 원인, 남은 자재, 하자, 3개월·1년 사용 후기를 축적한다.

## 11. 운영 원칙

- 가격과 법규처럼 변하는 정보는 사용할 때마다 다시 확인한다.
- 고객에게 사실, 추정, 추천을 명확히 구분해 전달한다.
- 개인정보가 포함된 현장 사진과 주소는 필요한 범위에서만 보관한다.
- 견적 오차와 변경 원인을 기록해 공간·평수·지역·공종별 기준을 지속적으로 개선한다.

## 12. 생활 문제 중심 설계 원칙

모든 시안은 스타일 이름이 아니라 `현재 문제 → 설계 개입 → 기대 효과 → 검증 방법`의 네 문장으로 시작한다.

- 현재 문제: 통로 간섭, 수납 부족, 채광, 환기, 가사 동선, 소음, 원상복구 등 실제 불편을 기록한다.
- 설계 개입: 가구 방향, 영역 분리, 세로 수납, 겸용 가구, 수리·재사용·교체 범위를 제안한다.
- 기대 효과: 통로 폭, 수납량, 작업 거리, 청소 시간처럼 가능한 항목은 수치로 표현한다.
- 검증 방법: 시공 전후 사진, 치수, 사용 후 인터뷰와 하자 기록으로 확인한다.
- 작은 공간은 침실·식사·업무·휴식의 영역을 먼저 나누고, 이동 경로와 문·서랍 간섭을 검토한다.
- 전월세 여부, 가족 구성, 보유 물품, 요리·청소 습관과 생애주기를 콘셉트보다 먼저 반영한다.

## 13. 셀프 작업 카드 표준

셀프 작업은 단순히 ‘가능’으로 표시하지 않고 작업별 카드로 제공한다.

1. 작업명과 범위
2. 난이도 A~E와 판단 이유
3. 예상 시간, 필요 인원, 건조·양생 시간
4. 공구, 보호구, 자재와 정확한 규격
5. 시작 전 현장 조건과 선행 공정
6. 단계별 핵심 순서
7. 흔한 실패, 손상 가능 부분과 재시공 비용
8. 즉시 중단하고 전문가에게 넘길 조건
9. 완료 후 작동·누수·수평·마감 검수
10. 남은 자재 보관과 추후 관리 주기

전기·가스·구조·방수와 매립 배관은 ‘할 수 있는가’보다 사고, 법규, 하자 책임과 복구 범위를 먼저 판단한다.

## 14. 수리·교체 의사결정

모든 노후 항목은 `세척·조정 → 부분 수리 → 표면 개선 → 부품 교체 → 전체 교체` 순서로 검토한다.

- 안전 문제, 반복 고장, 단종 부품, 내부 부식·누수는 전체 교체 또는 전문가 진단을 우선한다.
- 표면 손상은 바탕 보수와 접착·도장 적합성을 확인한 뒤 리폼 가능 여부를 판단한다.
- 교체비만 비교하지 않고 철거, 폐기, 운반, 보양, 복구와 사용 중단 기간까지 총비용에 포함한다.
- 완공 후 고객에게 청소 방법, 소모품 규격, 점검 주기, A/S 연락처와 응급 중단 방법을 제공한다.

## 15. 콘텐츠 분석 반영 원칙

2026-09-01부터 오늘의집과 쿤하우스를 포함한 선정 채널의 공개 콘텐츠를 채널 단위로 목록화하고 전수 분석한다. 대표 영상만으로 채널의 성격을 단정하지 않으며, 사례의 표현이나 디자인을 복제하지 않고 검증 가능한 원리만 공간한쪽 표준으로 재구성한다.

- 오늘의집: 거주자의 사연과 생활 문제에서 출발하고, 작은 공간의 영역 분리·수납·동선 변화가 어떤 효과를 내는지 전후 흐름으로 설명한다.

## 16. 견적·계약·업체 검증 원칙

아정당 인테리어의 공개 콘텐츠와 공개 견적·계약 자료에서 소비자 보호 관점을 분석해 다음 항목을 공간한쪽의 독립적인 기준으로 재구성한다.

### 견적 비교 전 조건 통일

- 업체별 견적은 동일한 도면, 공사 범위, 자재 브랜드·모델·규격·수량과 포함 조건으로 다시 정렬한다.
- ‘평당 가격’이나 총액만으로 비교하지 않고 공종별 자재비·노무비·경비·기업이윤·부가세를 분리한다.
- 미실측 견적은 확정 견적과 구분하고 실측 후 변동 가능한 항목과 상한을 표시한다.
- 철거, 폐기물, 양중, 보양, 바탕 보수, 배송, 청소처럼 누락되기 쉬운 비용을 별도 점검한다.

### 계약 전 업체 검증

- 사업자 정보, 실내건축공사업 등록 대상 여부, 현장 담당자와 실제 시공 주체를 확인한다.
- 동일하거나 유사한 공사의 최근 사례와 고객이 확인 가능한 하자 처리 기록을 요청한다.
- 계약금·착수금·중도금·잔금은 공정과 검수 시점에 연결하고 선지급 위험을 안내한다.
- 공사 기간, 지연 조건, 현장 출입, 폐기물 처리, 보양과 이웃 민원 책임을 계약서에 적는다.

### 추가금과 변경 관리

- 계약 전 예상 가능한 항목은 견적에 포함하고, 추가금이 가능한 조건은 구체적으로 열거한다.
- 철거 후 발견처럼 사전 확인이 어려운 항목은 사진, 수량, 단가와 공기 영향을 제시한 뒤 고객 승인 후 진행한다.
- 구두 변경은 인정 근거가 약하므로 변경 요청서에 작업 내용, 증감액, 일정 영향, 승인일을 남긴다.
- 고객 요청 변경과 현장 하자·업체 누락으로 인한 재시공 비용을 구분한다.

### 준공·A/S

- 잔금 전 공간별 검수표와 보수 완료 사진을 확인한다.
- 공종별 보증 범위, 기간, 제외 조건, 접수 방법과 처리 기한을 문서화한다.
- 하자보수보증보험 등 적용 가능한 보증 수단은 계약 전에 발급 주체와 보장 내용을 확인한다.
- 마감재 모델, 색상, 로트, 남은 자재와 설비 설명서를 고객에게 인계한다.

### 정보 독립성

- 특정 업체의 홍보성 주장, 보상 제도와 A/S 기간은 보편적인 업계 기준으로 단정하지 않는다.
- 업체가 제공한 정보와 공공기관·법령·계약서에서 확인한 사실을 분리해 표시한다.
- 공간한쪽은 특정 업체 추천보다 고객이 어느 업체든 동일한 조건으로 검증할 수 있는 질문과 서식을 제공한다.

## 17. 공정별 셀프 시공 가이드 표준

제안서에는 고객이 직접 수행하기로 선택한 모든 작업에 대해 다음 항목을 작업 카드로 제공한다.

1. 적용 위치와 정확한 작업 범위
2. 셀프 적합성 및 난이도 A~E와 판단 근거
3. 작업 전 바탕 상태와 수분·오염·파손 확인
4. 자재명, 제품·규격·색상, 필요량, 손실률, 구매처와 가격 확인일
5. 필수·선택 공구, 소모품, 보호구와 대여 가능 여부
6. 보양, 해체, 바탕 보수, 시공, 건조·양생, 재조립의 순서
7. 예상 시간, 필요 인원과 다음 공정까지 기다리는 시간
8. 흔한 실패와 예방 방법, 수정 가능 시간과 재시공 범위
9. 즉시 중단하고 부분 외주 또는 전문가에게 전환할 조건
10. 완료 검수, 청소 방법, 남은 자재 보관과 유지관리 주기

### 인테리어 필름

- 수분, 기름, 들뜸과 MDF 팽창을 확인하고 원인 손상은 덮지 않는다.
- 탈지·보수·샌딩·먼지 제거·프라이머 건조 후 재단과 부착을 진행한다.
- 넓은 문짝, 깊은 몰딩, 잦은 열·수분 노출 부위는 부분 외주를 비교한다.
- 기포, 주름, 모서리 들뜸, 칼자국과 문·서랍 간섭을 검수한다.

### 벽지

- 누수·결로·곰팡이는 원인을 해결한 뒤 시공한다.
- 기존 벽지 겹수, 바탕 강도, 초배 필요 여부와 무늬 맞춤 손실률을 확인한다.
- 높은 천장, 실크벽지 전체 시공과 심한 바탕 불량은 전문가 작업을 권한다.
- 이음, 기포, 오염, 모서리 들뜸과 건조 중 환기 조건을 검수한다.

### 도장

- 기존 도막과 새 도료의 적합성, 박리, 수분과 오염을 확인한다.
- 보양·세척·보수·샌딩·프라이머 후 얇게 여러 번 도장하고 제품별 재도장·경화 시간을 지킨다.
- 환기, 장갑, 보안경과 제품 안전자료에 맞는 마스크를 준비한다.
- 원인 미상의 습기, 유해 도막 의심, 외부 고소 작업은 전문가 확인 대상으로 분류한다.

### 기타 작업 확장

동일한 형식으로 실리콘, 줄눈, 장판, 걸레받이, 선반·손잡이, 조명기구, 가구 조립, 타일과 철거 작업 카드를 순차적으로 구축한다. 전기 회로, 가스, 구조, 욕실 방수와 매립 배관은 정보 제공과 별개로 전문가 확인을 기본값으로 둔다.
