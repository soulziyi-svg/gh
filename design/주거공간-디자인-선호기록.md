# 공간한쪽 주거공간 디자인 선호 기록

최종 갱신: 2026-09-05

## 분류 원칙

- 주거공간은 상업공간과 분리해 가족 구성, 생활 동선, 수납, 채광, 프라이버시, 가구 배치와 유지관리를 중심으로 분석한다.
- 레퍼런스를 그대로 복제하지 않고 현장 사진, 실측, 구조·설비 조건과 예산에 맞춰 새 시안으로 재구성한다.
- 사용자의 표현에 따라 선호 강도를 기록해 모든 참고 사례를 동일한 비중으로 사용하지 않는다.

## 68평 해운대 KCC스위첸

- 원문: https://todayinterior.com/g5/bbs/board.php?bo_table=project&wr_id=32&page=2
- 페이지 표기: 2025.04 / 68py / Gallery · Green
- 사용자 선호도: 중간 선호 — “디자인이 조금 괜찮은 것 같다.”
- 적용 수준: 최우선 디자인 기준으로 복제하지 않고 넓은 거실이나 갤러리형 주거공간에 적합할 때 선택적으로 반영한다.

### 선호 요소

- 화이트 갤러리 같은 중성 배경
- 올리브·세이지 그린을 벽 전체가 아닌 좌석·쿠션·패브릭에 제한적으로 사용
- 짙은 우드 가구로 밝은 공간의 중심을 잡는 방식
- 거실과 주방을 검정 프레임 슬라이딩 도어와 반투명 유리로 연결·분리
- 얇은 유리 선반, 작은 벽 니치, 세로 펜던트와 라인 조명이 만드는 전시 공간의 리듬
- 유리 드레스룸을 수납이면서 하나의 빛나는 장면으로 사용하는 방식

### 실제 적용 시 확인 사항

- 슬라이딩 도어의 유효 개구 폭, 레일 청소, 차음과 손 끼임
- 반투명 유리의 프라이버시 수준과 야간 실루엣
- 유리 선반의 허용 하중, 모서리 안전과 교체 가능성
- 유리 드레스룸의 환기, 지문·먼지 관리, 파손 안전
- 갤러리 조명과 생활 조명의 분리, 눈부심과 색온도

## 안동 한옥 스테이 ‘나스러움’

- 원문: https://www.interiorbay.co.kr/kwa-39008-120?category_2=02
- 프로젝트 표기: 경상북도 안동시 태화동 / GONG INTERIOR / 주택 30평대 / 전체 인테리어 / 10주
- 분류: 주거공간 · 한옥 리노베이션 · 스테이
- 적용 수준: 전통 구조와 현대 기능을 함께 다루는 시안의 주요 참고 사례

### 디자인 핵심

- 기와지붕, 처마, 노출 목구조, 격자창과 마당의 기존 질서를 보존
- 통유리와 세로 루버로 조망, 채광, 프라이버시를 단계적으로 조절
- 짙은 목재 프레임과 밝은 회벽, 월넛, 화강석, 백색 패브릭의 제한된 팔레트
- 침대와 벤치를 낮게 두고 긴 수평선을 사용해 한옥의 비례를 실내로 연결
- 주방·콘센트·수납·조명을 벽면과 하부 띠에 통합해 현대 설비의 시각적 잡음 최소화
- 마당을 모든 방이 공유하는 외부 거실이자 주요 시선축으로 사용

### 공간한쪽 적용 원칙

- 전통 문양을 표면에 복제하지 않고 구조선, 창살의 반복, 낮은 가구 높이와 재료 대비를 현대적으로 번역한다.
- 한옥이 아닌 아파트에는 짙은 수납 프레임, 밝은 미장벽, 낮은 벤치와 따뜻한 선형 조명만 선택적으로 적용한다.
- 구조 보강, 목재 균열, 단열·결로, 방습, 창호 기밀, 간접조명 점검구, 외부 배수와 미끄럼을 시안 단계부터 검토한다.

## 인테리어베이 아파트 12개 세트

- 원문: https://www.interiorbay.co.kr/kwa-39007?PB_1560822931=3
- 범위: 20~40평대 아파트 12개 / 이미지 174장 / 전체공사 10개·부분공사 2개
- 주요 학습: 공용부 개방, 긴 수납벽, 주방 확장, 알파룸, 현관 벤치, 클래식 아치, 컬러 포털, 부분공사 경계와 기존 가구 활용

### 적용 원칙

- 개방감은 무조건적인 벽 철거보다 천장선·바닥 방향·수납 전면과 개구부의 정렬로 만든다.
- 백색 공간에는 원목, 웜그레이, 우드 한 면, 얇은 금속 또는 패브릭 중 하나를 선택해 온도를 조절한다.
- 수납은 평수 기준이 아니라 신발·청소기·침구·팬트리·가전·재활용 등 실제 생활 목록으로 계산한다.
- 부분공사는 남길 바닥·문·창호·가구·가전을 먼저 정한 뒤 새 마감과 공사 경계를 맞춘다.
- 알파룸은 재택근무, 아이방, 팬트리, 드레스룸으로 바뀔 가능성을 고려해 조명·콘센트·환기와 수납을 범용적으로 설계한다.
