# 상세 견적서 엑셀 구성

## 권장 시트

1. `00_요약`: 예산, 공급가액, 부가세, 예비비, 최종 예상액, 신뢰도
2. `01_고객·현장`: 고객 요구, 건물·현장 조건, 실측일, 견적 기준일
3. `02_실측`: 공간별 치수와 사진 번호
4. `03_물량산출`: 산출식, 손실률, 포장 단위, 발주 수량
5. `04_상세견적`: 공종별 자재·노무·장비·경비
6. `05_마감재`: 제품, 성능, 가격, 판매처, 링크, 확인일, 대체품
7. `06_셀프·외주`: 안전 등급, 필요 공구, 작업자, 권장 방식
8. `07_업체비교`: 동일 범위 기준 업체별 단가·포함·제외·A/S
9. `08_공정표`: 선행 작업, 일정, 건조 시간, 담당자
10. `09_발주표`: 주문·배송·로트·반품·여분·보관
11. `10_변경관리`: 변경 사유, 증감액, 승인, 최종 금액
12. `11_검수`: 중간·준공 검수와 보수 완료
13. `12_실제정산`: 예상과 실제 비용·물량·기간 차이

## 계산 기준

- 공급가액 = 자재비 + 노무비 + 장비비 + 운반·폐기물비 + 기타 경비
- 부가세 = 과세 공급가액 × 적용 세율
- 예비비 = 예비비 적용 대상 금액 × 현장별 비율
- 최종 예상액 = 공급가액 + 부가세 + 예비비
- 발주 수량 = 손실률 반영 수량을 판매 포장 단위로 올림
- 셀프 절감액은 전문 시공 견적에서 셀프 수행에 실제로 제외되는 비용만 차감

## 표시 규칙

- 입력값, 계산값, 확인 필요 값을 색상으로 구분한다.
- 수식 셀은 잠그고 수동 입력 셀만 편집 가능하게 한다.
- 모든 가격에는 확인 날짜와 출처를 연결한다.
- 확정되지 않은 값은 0원으로 숨기지 않고 `미확정`으로 표시한다.
- 합계에는 필수, 선택, 보류, 제외 항목을 구분한다.
- 인쇄용 고객본과 내부 산출 근거본을 분리한다.

## 품질 확인

- 합계와 세금 계산 검증
- 단위 혼용 확인(m, ㎡, 장, BOX, EA, 식)
- 중복·누락 공정 확인
- 손실률과 포장 단위 확인
- 배송·양중·폐기물·보양·예비비 확인
- 판매가와 링크의 기준일 확인
- 견적 신뢰도와 추가 비용 조건 확인
