# 유튜브 인테리어 참고 데이터베이스

공간한쪽의 디자인·시공·견적 제안서에서 참고할 유튜브 자료를 출처 중심으로 관리합니다.

## 수집 대상

- 인테리어언니 백예진
- 오늘의집
- 쿤하우스
- 아정당 인테리어

## 저장 원칙

- 영상 원본과 전체 자막을 복제해 배포하지 않습니다.
- 영상 URL, 제목, 게시 정보와 분석 요약을 저장합니다.
- 디자인 원칙, 공간, 공종, 셀프 난이도, 장단점, 비용 언급을 구조화합니다.
- 시공 안전과 성능 관련 내용은 제조사 시방서·공식 기술자료로 교차 검증합니다.
- 가격은 영상 게시일과 지역·면적·자재 등급을 함께 기록하며 확정 견적으로 사용하지 않습니다.

## 분석 상태

`videos.analysis_status`는 `pending`, `metadata_ready`, `analyzed`, `needs_review`로 관리합니다.
새 영상은 기본적으로 `pending` 상태로 등록됩니다.
