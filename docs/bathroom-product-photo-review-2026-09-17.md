# 욕실 제품 사진 우선 UI

## 공개 승인 갱신
- 2026-09-17 사용자가 대화에서 "허락받았어"라고 사진 게시 허락 확보를 확인함.
- 이 사용자 확인에 근거하여 25개 이미지의 permission을 approved로 변경. 별도 허가 문서 검증을 했다는 뜻은 아님.
- 공개 도메인에서도 제품 이미지를 표시하도록 승인 상태 적용. 출처·비교용 표시·원본 비율·워터마크는 유지.
- 아래 권리 제한 내용은 승인 전 작업 기록이며 이 갱신이 현재 상태에 우선함.

## 구현 범위
- 5개 분류 × 5개 선택지에 대응하는 제품 이미지 25개 확인.
- 주거공간 분류 카드, 상세 상단, 사진 선택 목록, 제품 상세 이미지 연결.
- 확대 모달: 버튼/바깥 영역/Esc로 닫기, 닫은 뒤 원래 버튼으로 포커스 복귀.
- 원본 비율 유지. object-fit: contain, 원본 이상 강제 확대 및 워터마크 제거 없음.
- 기타 영상 가이드에 모델 확인 도기, 비교용 수전·타일·거울장 이미지 7개 연결. 영상 미공개 제품에 임의 사진을 동일 제품으로 표시하지 않음.

## 출처와 동일성
- js/bathroom-product-photos.js에 각 이미지 URL, 제품 원문, 모델, 출처와 권리 상태 기록.
- 대림 PL-1042: 제조사 제품 페이지의 이미지 다운로드 링크.
- PC-9050: 2255 판매 페이지 대표 이미지.
- 타일 5종: 백상타일의 오늘의집 개별 제품 페이지 대표 이미지. 시공 사례가 아니라 제품/패턴 이미지임.
- 비반트 VAR-340L, 루바인 FA01SH: 오케이세라믹·누오보 비교용 제품 사진. 영상 동일 모델 미확인 문구 유지.
- 나머지 모델: 개별 다나와 제품 페이지의 대표 제품 이미지. 미노아 BLACK, 동해 WHITE 등 옵션 대조. 원문 워터마크 유지.
- 국내 제조사, 판매처, 가격비교 및 해외 브랜드의 국내 자료를 대조. 사진 자체의 권리 확보 여부와 모델 일치 여부는 별개로 관리.

## 권리 / 배포 제한
- 공개 페이지에서 볼 수 있다는 이유만으로 재게시 권한이 생기지 않음.
- 외부 사진의 사이트 재게시 사용 허락은 확인되지 않았으므로 permission: pending.
- 허가 미확인 사진은 localhost/127.0.0.1/file 미리보기에서만 표시. 공개 도메인에서는 기존 화면 유지.
- 공개 반영 전 권리자가 허용한 제품 자료나 사용 허락 받은 원본을 확보하고 출처별 근거를 기록해야 함.
- 외부 연결 만료/차단 대비 오류 안내 및 원문 링크 제공. 자산을 무단 복제해 저장하지 않음.
- 이미지 발주·확인용 미리보기만 구현했으며 커밋·푸시·배포하지 않음.

## 검증
- 25개 제품 이미지 모두 브라우저로 육안 대조, 모델과 이미지 구성이 일치함을 확인.
- 5분류 각각 사진 상세 5개, 사진 선택 카드 5개 출력 확인.
- 390px에서 페이지 가로 넘침 없음.
- PC-9050 확대 이미지 로드, Esc 닫기, 버튼 포커스 복귀 확인.
- 제품 사진은 공급자가 제공하는 제품 이미지로, 직접 촬영된 실사인지 제조사 렌더인지 불명확할 수 있어 '제품 이미지'로 표시.
