# 욕실·현관 타일 디자인 및 추천 규칙

분석일: 2026-09-19. [영상 분석](ANALYSIS.md)과 [제품 후보표](PRODUCTS.md)를 함께 확인한다.

## 작업 전

- 현재 요청·실측·문과 창·배수·수납·청소 습관·예산을 먼저 확인한다. 현관은 신발 오염·문턱·신발장·실내 바닥의 연결을 함께 본다.
- 관련 원본 화면을 로컬 참고 자료에서 다시 확인한다. 공개본은 원본 사진을 포함하지 않는다. 접근하지 못하면 그 사실을 밝힌다.
- 자료 등록은 특정 스타일의 승인이나 모든 공간에 동일 타일을 사용하라는 지시가 아니다.

## 디자인 판단

1. 바탕·포인트·바닥의 역할을 나누고 무늬의 강도와 사용 면적을 정한다.
2. 석재 결의 방향·프린트 반복·줄눈색·모서리 접합을 함께 검토한다.
3. 대형 타일은 욕실 배수 경사와 현관 끝 조각까지 확인한다. 큰 규격이 항상 우수하다고 판단하지 않는다.
4. 입체 질감은 조명 위치와 홈 청소 부담을 함께 제안한다. 벽용 예시를 젖은 바닥용으로 전용하지 않는다.
5. 조명 아래 타일·도어·우드·상판의 색을 함께 비교한다.

## 제품 추천

- 영상 속 추천은 후보이며 구매 적합성의 증명이 아니다. 공식 제조사·모델·색·규격·마감·용도를 추천 시점에 검증한다.
- 가격은 장/박스/㎡ 단위, 배송·세금·시공 포함 여부와 확인일을 밝힌다. 확인되지 않은 가격을 채워 넣지 않는다.
- 미끄럼 성능은 표면의 외관·촉감·R값 언급만으로 확정하지 않는다. 젖은 맨발과 젖은 신발 등 사용 조건 및 관련 제품 자료를 확인한다.
- 자사 판매 주장과 전체 시장 순위를 구분한다. 자동 자막 제품명은 화면 교정표를 우선하되 공식 모델도 대조한다.
- 같은 영상에서 파생된 PPT와 요약을 독립된 여러 추천 근거로 중복 집계하지 않는다.

## 결과 기록

매 작업에 출처·영상 시점·직접 확인한 원본·실제 적용 위치와 이유·제외 이유·미확정 사항을 남긴다. 이미지 생성에 직접 입력한 참고와 글로만 전달한 참고를 구분한다. 실제 확인이나 적용 없이 반영 완료라고 말하지 않는다.

## 공개 자료 관리

원본 PPT·전체 자막·영상 캡처·개인 경로는 이 공개 폴더에 넣지 않는다. 본 문서는 재사용할 작업 기준이며 모델 자체의 영구 학습을 의미하지 않는다.
