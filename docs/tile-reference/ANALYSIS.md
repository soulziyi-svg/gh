## A — 공간별로 무엇을 추천하고 왜 추천하는가

### 0:20~3:22: 전체 접근

대형·무광·자연석 모티프를 소개하고 국가별 성격을 설명한다. 가져갈 원리는 줄눈 수와 면의 정돈이며, 국가별 우열은 구매 판단으로 채택하지 않는다. 강한 무늬일수록 프린트의 자연스러움을 더 자세히 비교하라는 발언은 **샘플을 여러 장 펼쳐 확인하는 절차**로 바꿔 사용한다.

### 3:26~6:02: 현관

핵심은 좁은 공간에서 신발장과 바닥을 함께 고르는 것이다. 아스팔트는 작은 점·섬유 같은 잔무늬, 루트 그레이는 중간 회색 바탕, 시에나 토스카노는 더 선명한 띠 무늬라는 서로 다른 역할로 소개된다. 5:28 비교 화면에서 시에나보다 토스카노가 더 노랗고 결의 대비가 강하게 보인다. 이는 해당 화면의 비교이지 실제 조명 아래 색을 보증하지 않는다.

실전 적용: 현관문·장·실내 바닥 중 이미 무늬가 강한 요소가 있으면 잔무늬 후보를 먼저 비교한다. 바닥을 주인공으로 삼을 때는 장의 표면을 정돈한다. 먼지가 덜 보인다는 발언은 오염 제거 성능과 분리한다.

### 6:14~8:24: 주방 미드웨이

상·하부장 사이의 높이와 장 분할에 맞춰 줄눈을 배치한다. 801 MB의800각, 302와 하임 베이지의600각/600×1200 언급을 확인했다. 하임은 자막에 ‘하인’으로 나오지만 8:18 제품 화면에는 **하임 베이지1200**이다. 우드와 베이지를 연결하거나 스톤 상판과 결을 맞추는 판단에 활용한다. 모든 주방에800높이가 맞는다는 의미는 아니다.

### 8:37~12:34: 욕실

시에나는 차분한 트라버틴 계열, 파타고니아는 강한 석재 무늬, 라보나는 바닥 후보로 소개된다. 벽 시에나+바닥 라보나 조합을 명시한다. 파타고니아는 라인 조명과 함께 보여주지만 작은 공간에서 전시장 같은 효과가 나지 않을 수 있다는 경고도 있다. 실제 확인한 욕실 화면은 세면대 쪽의 강한 무늬와 주변 잔잔한 면을 대비시킨다.

실전 적용: 강한 패턴은 방 전체가 아니라 시선이 모이는 면부터 검토한다. 벽·바닥을 같은 제품으로 통일하는 대신 역할별로 나눌 수 있다. ‘절대 미끄러지지 않을 것 같은 느낌’은 안전 근거로 사용하지 않는다.

### 12:45~14:00: 추가 조합

실물을 직접 보고 고르도록 권하고, 파타고니아 벽+캐니언 아이보리 바닥 조합을 추가한다. 이 조합은 출처 제안으로 기억하되 실제 바닥용 적합성·샘플·현재 모델을 확인한 후 채택한다.

## B — 2025 판매 설명과 2026 제안을 분리

### 1:04~2:12: 판매 주장

출연자는 자신들의2025판매 데이터를 근거로 라보나1위, 시에나2위, 캐니언 아이보리도 인기 제품이었다고 설명한다. 캐니언을 명시적으로 ‘3위’라고 단정하지 않는다. 원 판매자료·집계 범위는 공개 확인하지 않았다. 따라서 **영림 영상에서 밝힌 자사 판매 기준의 설명**이라고만 인용한다. 전국 시장 순위도,2026현재 순위도 아니다.

### 3:25~4:47: 쉘스톤

조개 자체가 들어갔다는 설명이 아니라 화석·단면을 연상시키는 패턴이다. 장면의 배경 욕실은 특정 쉘스톤 상품으로 식별되지 않았으므로 캡처 배경을 곧바로 제품 이미지로 붙이지 않는다. 실제 추천에는 패턴의 입자·불규칙성·명암을 확인할 샘플이 필요하다.

### 4:50~6:25: 타지마알·트라버틴 비교

흐르는 가지형 결과 층리형 결의 차이가 중심이다. 특정 단일 SKU가 아니라 패턴 계열로 관리한다. 타지마할 건축물 재료에 관한 발언은 기존 PPT 분석에서 지적한 오류와 연결되므로 사실 설명에서 제외한다. 취향에 따라 바탕/포인트를 정하고 타일 여러 장과 모서리의 결 방향을 확인한다.

### 6:27~7:47: 리브드

평면 프린트와 달리 실제 요철과 빛의 그림자를 강조한다. 한 벽을 입체감 있는 면으로 만들고 나머지를 평평하게 정돈하는 제안을 도입한다. 7:24 예시는 가로 결·어두운 하부장·거울 양옆 벽등·투명 샤워 파티션의 조합이다. 특정 상품·실제 시공 사진인지까지 검증된 것은 아니다.

### 7:48~9:59: 영림 신제품과 쇼룸

잔잔한 디자인과 습식 환경을 고려한 제품을 소개하며3월 전시·출시 예정이라고 말한다. 현재 출시 이행·정확한 모델·성능은 확인하지 않았다. ‘2026년에는 이 제품을 사야 한다’가 아니라 원출처가 제안한 방향으로 관리한다.

## C — 유형 선택과 실무 조건

### 0:39~1:20: 아이보리 무광

해당 매장의 자주 판매되는 후보를 소개한다. 화면은66074·66055·66109·VENUS BEIGE·BLT IVORY이다. 자동 자막/PPT의6605는 **66055로 교정**한다. 따뜻하고 차분한 바탕 후보이지만 ‘모든 공간에 무조건’은 채택하지 않는다. 작은 샘플과 실제 넓은 면의 색은 다르게 보일 수 있다.

### 1:23~2:09: 마블

포인트 벽과 패턴 반복 확인이 핵심이다. 보여준 석재 패널은 흰·크림 바탕에 가는 회색 결과 넓은 덩어리 무늬가 섞인다. 화면의 특정 패널을 발언한 특정 모델로 일대일 식별하지 않았다. 여러 페이스를 배치해 반복과 모서리 접합을 확인한다.

### 2:11~2:56: 젤리지

작은 유광 타일의 색차·반사로 분위기를 만든다. 2:20 화면은 회청색 샘플과 여러 색의 작은 격자 패턴이며 #MELAN 표기가 보인다. 자막 명칭과 공식 모델의 일치는 추가 확인 대상이다. 유광 반사를 좋아하는 취향에 한 면 후보로 쓰고 젖은 바닥 적합성을 추정하지 않는다.

### 2:58~3:38: 텍스처

3:10 화면 카드에는 **Turtle / ES GROOVED / MOTLEY**가 적혀 있다. PPT의‘타를’, 자막의‘타틀’ 같은 한글을 그대로 상품 검색의 확정명으로 사용하지 않는다. 이들은 동일한 깊이의 리브가 아니라 표면 질감 계열로 묶여 소개된 후보이다. 조명과 청소 조건을 붙여 제안한다.

### 3:41~4:28: 트라버틴

3:55 제품 카드에서 **STLA6002, STLA6003, ELYSIAN07(EY07)**를 확인했다. 자막의6200/603/이와의07과 다르다. 트라비스는 자막 언급을 확인했지만 정확한 영문 모델은 미확정이다. 따뜻한 띠 무늬와 주변 우드의 결이 경쟁하지 않도록 조절한다. 모든 타일이 서로 다른 무늬라는 보장은 아니다.

### 4:31~5:32: 규격

300×600벽+300각바닥과600각포세린을 비교한다. ‘20평대 아파트 화장실 약1.5평’이라는 구체적 문맥으로 기존 PPT의 모호함을 해소한다. 이는 모든1.5평욕실의 시공 승인 기준이 아니다. 배수구·경사·절단·바탕·시공자 검토가 먼저다.

### 5:34~6:33: 조명

샘플과 집의 조명 차이, 벽등의 분위기 효과를 설명한다. 영상 자막의 조명 용어는 오인식이 있어 정확한 색온도 숫자로 바꾸지 않는다. 계획 조명 아래 실물과 인접 재료를 함께 보는 절차로 적용한다. 계절별 판매 취향을 사용자의 영구 취향으로 간주하지 않는다.

### 6:35~7:58: 기능·비용

배수 경사와 장기 교체 부담을 강조한다. ‘거친 표면은 덜 미끄럽다’,‘싼 타일은 깨진다’는 일반화만으로 구매를 결정하지 않는다. 제품 용도·관련 시험·바탕·시공 상태와 총비용을 비교하는 판단으로 전환한다.

## 실제 추천 절차에 추가할 사항

1. 먼저 바탕/포인트/바닥용 역할과 현재 공간 조건을 정한다.
2. [제품 후보표](PRODUCTS.md)에서 조건에 맞는 후보만 추린다. 영상에 나왔다는 이유로 모두 추천하지 않는다.
3. 사용자에게 출처·발언 시점·추천 이유·디자인 적용 면을 제시한다.
4. 화면에서 확인한 모델명으로 공식 판매 자료를 조회하고 가격·규격·용도·성능을 확인한다. 영상 가격으로 현재 견적을 만들지 않는다.
5. 미끄럼 저항은 외관·촉감·R값 언급만으로 승인하지 않는다. 용도별 검증이 없는 후보는 구매 확정 추천에서 제외하거나 보류 표시한다.
6. 시각화에는 확인한 참고 이미지를 직접 입력하되 실제 상품 색/질감 재현을 보증하지 않는다. 화면의 배경 타일을 설명 중인 제품으로 오인하지 않는다.
7. 무엇을 반영하고 무엇을 제외했는지 기록한다. 자료 조회만 하고 반영했다고 말하지 않는다.

## 기존 PPT 분석에 대한 교정

- 6605 → 화면 확인66055.
- STLA6200/603 → 화면 확인STLA6002/6003.
- 이와이07 → 화면 확인ELYSIAN07(EY07).
- 타를/타틀 → 화면 확인Turtle. ES GROOVED와 MOTLEY도 영문 표기 우선.
- 하임 베이지: A 영상의 추가 대안으로 보완.
- ‘20평대 욕실’ → C의 문맥은20평대 아파트 안 약1.5평욕실.
- 기존 PPT와 이번 영상의 내용이 겹치므로 **독립된 여러 출처의 합의**로 중복 집계하지 않는다. A와 B도 같은YOUNGLIM 채널이다.

## 공개 범위와 활용

이 문서는 분석 요약 공개본이다. 원본 PPT·자막·캡처와 개인 로컬 경로는 포함하지 않는다. 실제 시각화 작업에는 별도로 보관한 원본을 다시 확인한다. 원본에 접근할 수 없으면 이미지 대조를 완료했다고 표현하지 않는다.

[적용 규칙](DESIGN-RULES.md)에 따라 제품의 현재 사양과 용도를 검증한다. 모델 자체의 영구 학습, 전 영상 연속 시청, 모든 상품 검증을 의미하지 않는다.
