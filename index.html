어떤 공간을 바꾸고 싶으신가요?

RENOVATION METHOD GUIDE

핵심 차이는 누가 선택하고, 관리하고, 책임지느냐입니다.

같은 디자인이라도 누가 자재를 고르고, 기술자를 섭외하고, 공정표를 관리하며, 하자를 책임지는지에 따라 실제 비용과 피로도가 크게 달라집니다. 단순히 계약 금액만 비교하지 말고 내가 현장소장 역할까지 맡을 수 있는지, 문제가 생겼을 때 누구에게 해결을 요청할 수 있는지를 함께 살펴보세요.

DIY · 직접 시공

셀프

공간 계획과 자재 구매는 물론, 안전하게 할 수 있는 철거·도장·필름·가구 조립 등의 작업까지 본인이 직접 수행하는 방식입니다. 작업 범위를 작게 나누면 비용을 줄일 수 있지만, 시공 품질과 복구 책임도 본인에게 돌아옵니다.

  • 외주가 필요한 일부 공정은 작업 범위와 책임을 별도로 협의

  • 인건비를 줄이고 제품과 작업 순서를 자유롭게 선택
  • 작은 범위를 일정에 맞춰 나누어 진행 가능
  • 방수·전기·가스·구조 공사는 안전과 하자 위험이 커 전문가 필요
  • 잘못된 실측이나 시공은 자재 재구매와 복구비로 이어질 수 있음

DIRECT · 직영 공사

반셀프

시공은 철거·전기·목공·타일·도장·도배 등 공정별 전문가에게 맡기되, 사용자가 현장소장처럼 전체 디자인과 예산, 작업자 섭외, 자재 발주, 일정과 현장 감리를 직접 총괄하는 방식입니다.

진행 구조

  • 선행 공정의 치수와 마감 상태를 확인한 뒤 다음 작업자에게 정확히 인계

장점과 주의점

  • 업체 관리비와 중간 마진을 줄여 자재 등급에 예산을 더 배분 가능
  • 타일·수전·스위치까지 취향과 예산에 맞게 직접 선택
  • 자재가 늦거나 한 공정이 밀리면 다음 작업자 일정과 전체 공기가 연쇄 변경
  • 누수처럼 여러 공정이 얽힌 하자는 책임 소재를 직접 판단·조율해야 함
현장에 시간을 쓰며 예산과 취향을 직접 관리할 분에게 적합
TURN-KEY · 일괄 계약

턴키

한 인테리어 업체에 디자인과 자재 선정, 철거·목공·타일·전기·도배 등의 시공, 작업자 배치, 공정표와 현장관리까지 일괄 위임하는 방식입니다. 완공 후 바로 입주할 수 있도록 통합 관리받는 형태입니다.

초기 비용
비교적 높은 편
시간·체력
가장 적게 필요
현장 관리
업체 전담

진행 구조

  • 상담·실측 → 디자인·3D 시안 → 세부 견적·계약 → 업체 공정 관리 → 검수·A/S
  • 변경 사항과 추가 비용은 계약 업체 담당자를 통해 한 창구로 협의

장점과 주의점

  • 전문가가 현장 감리와 일정을 관리해 본업과 일상을 유지하기 쉬움
  • 전체 디자인의 통일감과 마감 품질을 비교적 안정적으로 관리
  • 감리비·관리비·업체 이윤이 포함되어 반셀프보다 계약 금액이 높을 수 있음
  • 결과가 업체의 견적 투명성, 소통과 현장 관리 역량에 크게 좌우됨
시간 절약, 통일된 마감과 일괄 A/S를 우선할 분에게 적합

상황에 맞춰 선택하세요

  • 시간이 더 중요한 경우: 직장·육아로 현장에 자주 갈 수 없거나 경험이 적고, 디자인부터 A/S까지 한 창구로 관리받고 싶다면 턴키
  • 예산과 취향 통제가 중요한 경우: 공정을 공부하고 현장에 시간을 투입할 수 있으며, 자재와 기술자를 직접 선택하고 싶다면 반셀프
  • 작은 범위를 직접 바꾸는 경우: 안전 위험이 낮은 부분 시공이고 필요한 공구와 경험을 갖췄다면 셀프
  • 비용 차이의 의미: 턴키 금액에는 업체의 일정 조율·감리·책임 비용이 포함되며, 반셀프의 절감분은 사용자의 시간과 관리 노동으로 대체됨

계약과 공사 전에 반드시 확인하세요

  • 자재의 브랜드·모델·색상·수량, 철거·보양·폐기물 처리와 부가세까지 적힌 세부 견적
  • 공정 순서와 기간, 자재 지연·현장 변수 발생 시 대응, 추가 공사 승인 방식과 대금 지급 시점
  • 도면과 3D 시안에 표현되지 않은 몰딩·걸레받이·문선·콘센트·조명 위치 등의 마감 기준
  • 공정별 담당자, 검수 기준, 하자 보수 범위·기간·연락 창구를 계약서나 메시지로 명확히 기록
  • 전기·가스·방수·배관·구조처럼 사고와 복구 비용이 큰 공정은 자격과 경험을 갖춘 전문가가 맡는지 확인
반셀프 실전 체크

공정표와 현장 인계를 직접 관리합니다

  1. 공정 순서: 철거 → 설비·창호 → 전기·목공 → 타일 → 욕실 세팅 → 필름 → 도배 → 마루 → 가구·조명 순서를 기본으로 잡고, 앞 공정 지연에 대비해 공정 사이에 여유 일정을 둡니다.
  2. 자재와 양중: 시공일 전에 품목·수량·도착 시간을 확인하고, 엘리베이터나 사다리차를 이용한 현장 운반이 견적에 포함되는지 미리 협의합니다.
  3. 공사 신고: 공동주택은 관리사무소의 공사 신고, 소음 공정 안내, 주민 동의, 엘리베이터 보양과 사용료 등 단지별 절차를 사전에 확인합니다.
  4. 작업 범위: 기술자와 일당만 합의하지 말고 하루 작업 범위, 인원, 자재·공구 준비 주체, 마감과 재방문 조건까지 기록합니다.
  5. 돌발 상황: 철거 뒤 옹벽·누수·노후 배관이 발견될 수 있으므로 예비비와 의사결정 시간을 확보하고, 어려운 기초 공정만 업체에 맡기는 부분 반셀프도 검토합니다.
턴키 계약 체크

업체의 자격과 계약 문서를 확인합니다

  1. 업체 검증: 공사 규모에 필요한 실내건축공사업 등록 여부, 사업자 정보, 실제 포트폴리오와 최근 현장, 담당 현장소장의 소통 방식을 확인합니다.
  2. 세부 견적: ‘전체 공사 일괄’ 같은 통견적 대신 공정별 자재 품명·규격·단가·수량·인건비·폐기물 비용을 적은 산출 내역서를 받습니다.
  3. 표준 계약: 공사 범위와 기간, 계약금·중도금·잔금 시점, 공사 지연 시 기준, 설계 변경과 추가 비용 승인 절차를 계약서에 명시합니다.
  4. 검수와 잔금: 준공 전에 도면·견적과 실제 시공을 대조해 하자 목록을 작성하고, 보완 완료를 확인한 뒤 잔금을 지급하도록 일정을 잡습니다.
  5. A/S 보증: 하자보수 범위와 기간, 접수 창구를 확인하고 계약 조건에 맞는 하자보수 보증 문서의 발급 가능 여부도 협의합니다.
