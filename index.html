ROOM PICK PROCESS

인테리어 셀프·반셀프·턴키 고민이시라면 사진 한 장으로 시작해서 최종 제안서까지

  1. START 사진 한 장으로 신청

    현재 공간 사진과 간단한 실측 정보를 보내주세요.

  2. 01 SAMPLE 디자인 시안 (가견적)

    공간의 가능성과 예상 비용 범위를 먼저 확인합니다.

  3. 02 구매 진행

    샘플 방향이 마음에 들면 정식 디자인을 시작합니다.

  4. 03 여러 컨셉 디자인 시안

    여러 방향의 디자인과 상세 견적을 비교하고 수정합니다.

  5. 04 최종 디자인 확정 제안서

    확정된 디자인과 실행 기준을 최종 제안서로 정리합니다.
